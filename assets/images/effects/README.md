# Emote rain — masukkan PNG milikmu di folder ini

Accepted: `happy-1.png`, `happy-2.png`, `happy-3.png`, `happy-4.png`.

Not-accepted: `sad-1.png`, `sad-2.png`, `sad-3.png`, `sad-4.png`.

Nama huruf kecil, case-sensitive. Gunakan PNG persegi transparan (misalnya 128–256 px), ukuran file ringan. Tidak ada gambar pengganti dalam paket ini. Cukup salin gambar ke sini dan reload halaman; tidak perlu mengubah HTML/JS. Aset hilang dicache selama halaman masih terbuka, jadi reload diperlukan setelah menambahkan file.

Efek hanya berjalan setelah hasil accepted/not-accepted tampil, 12 partikel pada mobile dan 18 pada layar lebih lebar. Aset yang belum ada/rusak dilewati. Tanpa aset, hasil tetap tampil tanpa efek. Reduced motion menonaktifkan efek.

Gambar utama kartu hasil tetap menggunakan path existing di folder induk, bukan delapan PNG ini. Panduan menjalankan dan debugging ada di `docs/EMOTE-RAIN.md` dari root proyek.
